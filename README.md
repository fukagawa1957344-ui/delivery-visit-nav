# 配送・訪問ナビ

GitHub Pages用の静的Webアプリです。`main`ブランチへpushするとGitHub ActionsがPagesへデプロイします。

- 配信するファイルは `site/` にあります。
- 道路地図には OpenStreetMap を使い、拡大上限はズーム19です。タイル配信は公開コミュニティサービスのため、利用量・提供状況に制約があります。
- 航空写真には国土地理院の「全国最新写真（シームレス）」を使います。写真の撮影時期は地域により異なり、ズーム18を超える拡大では画像が拡大表示されます。
- アプリ内の経路は交通渋滞に対応しません。目的地を選ぶとGoogleマップで同じ地点を比較・案内できます。
- 現場写真はブラウザーのIndexedDBに端末ごとに保存され、GitHubへ送信しません。
- 現在地・目的地座標は位置情報や経路検索時に外部APIへ送信されます。
- GitHub PagesのHTTPS配信を前提にPWAと位置情報を利用します。
